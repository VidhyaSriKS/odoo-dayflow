# Dayflow Hackathon Demo Script (3-5 Minutes)

### 0:00 - 0:30 | Introduction & Landing Page
- Presenter opens Dayflow landing page (`http://localhost:5173`).
- Highlight tagline: *"Every workday, perfectly aligned."*
- Click **View Demo** or **Demo Accounts** button.

### 0:30 - 1:30 | Employee Workflow
1. Click **Login as Employee** (`employee@dayflow.com` / `Employee@123`).
2. Show Employee Dashboard:
   - Point out top metric cards (Present Today, 8h 32m, Leave Balance: 12 days, Attendance Rate: 94.2%).
3. Perform **Check-In**:
   - Click **Check In** button. Live status updates to *Checked In* with real-time check-in time.
4. Apply for Leave:
   - Navigate to **Leave Management**, click **Apply for Leave**.
   - Select *Sick Leave*, set date range (e.g. tomorrow), type reason: *"Fever and rest recommended by doctor"*, submit.
   - Show status set to **PENDING**.
5. Log out.

### 1:30 - 3:00 | HR Admin Workflow
1. Click **Login as Admin** (`admin@dayflow.com` / `Admin@123`).
2. Show HR Dashboard:
   - Highlight organization metrics (Total Employees: 250, Present: 218, Pending Leaves: 12, Attendance: 87.2%).
   - Point out Recharts graphs (Attendance trends & Department distribution).
3. Process Pending Leave Request:
   - Navigate to **Leave Approvals**.
   - Locate Alex Taylor's pending Sick Leave request.
   - Click **Approve**. Show status update, notification creation, and leave balance update.
4. Employee Management:
   - Navigate to **Employees**.
   - Search for employee by name or department. Click **View Details** to inspect employee profile and salary structure.

### 3:00 - 4:00 | AI HR Assistant & Insights
1. Navigate to **AI Assistant**:
   - Ask: *"How many employees are absent today?"*
   - Show instant AI response reflecting actual backend database state.
2. View **AI Attendance Insights**:
   - Show automated tardiness and attendance pattern alerts for flagged employees.

### 4:00 - 4:30 | Wrap-up & Impact
- Summarize seamless workflow integration, security, real-time analytics, and enterprise readiness.
